VALIDACION DE FORMULARIOS

HTML5 trajo consigo la capacidad de validar la información que los usuarios introducen en los formularios de forma nativa. Esto significa que el propio navegador web se encarga de comprobar si los datos son correctos antes de enviarlos, sin necesidad de escribir código adicional en JavaScript.

  • Attribute Required
    • Marca un campo como obligatorio
  • Attribute Pattern
    • Permite definir un patron con expresiones regulares para validar la entrada del usuario
