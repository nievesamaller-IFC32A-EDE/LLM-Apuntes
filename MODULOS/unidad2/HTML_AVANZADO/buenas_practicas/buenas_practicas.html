BUENAS PRACTICAS EN FORMULARIOS HTML

Aplicar buenas prácticas al crear formularios es esencial para mejorar la experiencia del usuario, la accesibilidad, la seguridad y la eficiencia de tu página web.

Aquí tienes la lista de recomendaciones clave y cómo aplicarlas en tu código:

  • Accesibilidad y Claridad:
    • Utiliza siempre la etiqueta <label> enlazada a cada campo, esto es fundamental para mejorar la accesibilidad de la web.
    • Usa el atributo placeholder para mostrar textos de ejemplo que proporcionen pistas visuales sobre lo que el usuario debe escribir.
  • Validación y Eficiencia:
    • Elige los tipos de entrada adecuados (por ejemplo, type="email" en lugar de texto normal) según los datos que necesites.
    • Aplica el atributo required para definir qué campos son obligatorios antes de enviar el formulario.
    • Añade validación nativa apoyándote en atributos como pattern, min o max para restringir lo que se puede introducir.
    • Utiliza la función autocomplete para ayudar al usuario a rellenar el formulario más rápido.
  • Estructura y Control de Errores
    • Organización: Agrupa los campos del formulario de forma lógica. El bloque de código muestra cómo hacerlo usando la etiqueta <fieldset> (que crea una caja agrupadora) y <legend> (que le da un título a esa caja, como "Informació Personal").


    • Gestión de errores: Debes proporcionar información clara sobre los errores. El código inferior muestra cómo usar un evento de JavaScript integrado (oninvalid="this.setCustomValidity('...')" ) para cambiar el mensaje de error genérico del navegador por uno personalizado y claro si el correo introducido no es válido.
