METADATOS CON HTML

Las metadades son información crucial que se coloca dentro de la etiqueta <head> del documento HTML. Aunque no se muestran directamente en la página web que ve el usuario, son esenciales para describir las características del documento y proporcionar instrucciones a navegadores, motores de búsqueda (como Google) y otras aplicaciones.

  1. Configuración Básica del Documento
    • Charset: Define el conjunto de caracteres. Se recomienda usar UTF-8 (<meta charset="UTF-8">), ya que soporta casi todos los caracteres y símbolos del mundo, evitando que el texto se vea con errores.
    • Viewport: Fundamental para el diseño web responsivo (<meta name="viewport" content="...">). Garantiza que el contenido se adapte y escale correctamente en diferentes tamaños de pantalla, especialmente en dispositivos móviles.
  2. Información para el SEO y Buscadores
    • Description: Proporciona un breve resumen de la página web (<meta name="description" content="...">). Los motores de búsqueda suelen usar este texto para mostrar la descripción en los resultados de búsqueda.
    • Keywords: Una lista de palabras clave (<meta name="keywords" content="...">). Aunque hoy en día no es tan relevante para el posicionamiento principal, describe los temas centrales de la página.
    • Author: Indica el autor o la empresa responsable de crear el contenido (<meta name="author" content="...">).
  3. Interacción con Motores de Búsqueda y Redes Sociales
    • Robots: Da instrucciones directas a los motores de búsqueda sobre si deben indexar la página y seguir sus enlaces (ej. <meta name="robots" content="index, follow">).
    • Open Graph Tags (OG): Estas metadades (ej. og:title, og:image) son utilizadas por redes sociales como Facebook o Twitter para mostrar previsualizaciones atractivas y personalizadas (con título, descripción y foto) cuando alguien comparte el enlace de tu web.
  4. Elementos Visuales e Idioma
    • Iconos para móviles: Se pueden definir iconos específicos (ej. apple-touch-icon) para cuando un usuario guarda tu página web en la pantalla de inicio de su teléfono.
    • Favicon: Aunque usa la etiqueta <link> en lugar de <meta>, es un dato visual importante (<link rel="icon" ...>). Es el pequeño icono que aparece en la pestaña del navegador, junto al título de la página.
    • Atributo lang: Se define directamente en la etiqueta principal <html> (ej. <html lang="ca">) para especificar el idioma general de la página, lo que es vital para la accesibilidad y el SEO.
