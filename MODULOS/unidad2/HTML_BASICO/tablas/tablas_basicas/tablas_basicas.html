TABLAS BASICAS

En HTML, las tablas sirven para organizar información en filas y celdas. Para crearlas, usamos etiquetas que indican dónde empieza la tabla, cómo se forman sus filas y dónde va cada dato.

Etiquetas para crear tablas:

  1. <'table>: Es el contenedor principal. Dentro de él se escriben todas las filas y los datos de la tabla.
  2. <'tr>: Crea una fila horizontal en la tabla.
  3. <'td>: Crea una celda dentro de una fila. Ahí se coloca un dato, como un nombre o una edad.

Atributos de la tabla:

  1. border: Añade líneas alrededor de la tabla y sus celdas.
  2. cellpadding: Deja espacio dentro de cada celda, entre el texto y el borde.
  3. cellspacing: Deja espacio entre una celda y otra.
