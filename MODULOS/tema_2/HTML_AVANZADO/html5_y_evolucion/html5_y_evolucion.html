HTML5 Y SU ESTRUCTURA BASICA

HTML5 supone una evolución importante frente a versiones anteriores, introduciendo nuevas etiquetas y funciones para mejorar la gestión multimedia, los formularios y la semántica de la página web.

Etiquetas Clave en HTML5 para memorizar:

  1. <'section>: Agrupa contenido relacionado dentro de una página.
  2. <'article>: Representa un bloque de contenido totalmente autónomo que puede existir de forma independiente (ej. artículo de blog o noticia).
  3. <'aside>: Define contenido relacionado con el principal pero que no es esencial, utilizado típicamente para barras laterales, anuncios o información complementaria.
  4. <'header> y <'footer>: Sirven para definir las cabeceras y los pies de página.
  5. <'nav>: Especifica las áreas destinadas a las barras de navegación del sitio web.
  6. <'figure> y <'figcaption>: Agrupan elementos multimedia (como imágenes o vídeos) junto con sus respectivas descripciones o leyendas.
