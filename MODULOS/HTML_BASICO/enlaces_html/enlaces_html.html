ENLACES EN HTML

Para crear un enlace en HTML usamos <'a>. El atributo href indica adónde lleva el enlace, y el texto entre <'a> y <'/a> es lo que la persona verá y podrá pulsar.
Por ejemplo:

'Href' puede llevar a otra página web o a una parte de la misma página. Si queremos que el enlace se abra en otra pestaña, usamos target="_blank".
Conviene usarlo solo cuando sea necesario y escribir un texto claro que explique adónde lleva el enlace.


El atributo target indica dónde se abrirá el enlace:

  • target="_self": abre el enlace en la misma pestaña. Es la opción predeterminada, así que normalmente no hace falta escribirla.
  • target="_blank": abre el enlace en una pestaña nueva.
