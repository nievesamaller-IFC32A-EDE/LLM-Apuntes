ELEMENTOS HTML Y ANIDAMIENTOS

En HTML, una etiqueta (tag) y un elemento no son exactamente lo mismo. Una etiqueta es una parte del código que marca dónde empieza o termina algo. Por ejemplo, <'p> es la etiqueta de apertura y <'/p> es la etiqueta de cierre.



Se delimita con los simbolos < >.



El elemento es el conjunto completo: la etiqueta de apertura, el contenido y la etiqueta de cierre. En <'p> Hola <'/p> , todo junto es un elemento de párrafo. El navegador lee esas etiquetas para entender qué tipo de contenido hay y cómo organizarlo.





Los elementos pueden anidarse, es decir, colocarse uno dentro de otro. Por ejemplo, <'body> contiene el contenido visible de la página, y dentro de él podemos poner títulos y párrafos.


Los elementos correctamente anidados ayudan al navegador a interpretar la página y hacen que el código sea más fácil de entender y mantener.


ALERT!

Hay que cerrar los elementos en el orden correcto: primero se cierra el que se abrió al final.
