QUE ES HTML?

El HTML (por sus siglas en inglés, HyperText Markup Language, o Lenguaje de Marcado de Hipertexto) es el lenguaje estándar que se utiliza para crear y estructurar el contenido de las páginas web.

PARA QUE SIRVE?

• Es el esqueleto de la web: Define la estructura básica y la jerarquía de una página (títulos, párrafos, listas, tablas).
• Integra recursos: Permite insertar imágenes, vídeos, audios y enlaces (hipertextos) que conectan unas páginas con otras.
• Guía al navegador: Le indica a navegadores como Chrome, Firefox o Safari cómo deben organizar los elementos en la pantalla

COMO FUNCIONA?

Funciona mediante etiquetas que envuelven el contenido y le asignan un significado.
No es un lenguaje de programación (no tiene lógica, variables o bucles), sino un lenguaje de marcado. Para funcionar en una página web moderna, suele complementarse con otras tecnologías:
• CSS: Se encarga del diseño visual, los colores y los estilos.
• JavaScript: Añade la interactividad y el dinamismo.
