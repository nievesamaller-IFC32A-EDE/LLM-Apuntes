ESTRUCTURA BASICA

Un documento HTML tiene un orden, como una caja dentro de otra. Las etiquetas ayudan a organizar las partes de una página. Casi todas las páginas empiezan con <"!DOCTYPE html>, que le indica al navegador que el documento usa HTML. Después viene <"html>, que contiene toda la página. Dentro están <"head>, con información sobre la página, y <"body>, con lo que vemos en pantalla, como títulos, texto e imágenes.
