ETIQUETAS BASICAS

En HTML hay etiquetas básicas para organizar el contenido de una página. <'title> pone el nombre que aparece en la pestaña del navegador. <'h1> hasta <'h6> sirven para crear títulos, desde el más importante hasta el menos importante. <'p> marca un párrafo. <'br> hace que el texto continúe en la línea siguiente. (' ) añade un espacio que no se separa al final de una línea.

ALERT!

Una pequeña precisión: <'br> se escribe sin etiqueta de cierre. Y normalmente es mejor separar palabras con espacios normales; (' ) se usa solo cuando queremos evitar que ciertas palabras se separen al final de una línea.
