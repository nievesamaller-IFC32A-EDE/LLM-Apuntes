ATRIBUTOS HTML

Los atributos añaden información extra o configuración a una etiqueta HTML. Se escriben dentro de la etiqueta de apertura, normalmente con este formato: nombre="valor". Sirven para modificar el comportamiento o la apariencia.

En el ejemplo, id, class, style, title, src, alt y href son atributos. Por ejemplo, href indica a dónde lleva un enlace y src señala la dirección de una imagen. El atributo alt contiene una descripción de la imagen que puede ayudar a quienes usan lectores de pantalla o cuando la imagen no se carga.

ALERT!

Id y class ayudan a identificar elementos de una página. id sirve para identificar un elemento concreto. class permite agrupar varios elementos para darles el mismo estilo con CSS.
Muchos atributos se escriben como nombre="valor". Por ejemplo, id="titulo" significa que el valor del atributo id es titulo. Algunos atributos tienen otra forma de escribirse, así que ese formato no se aplica a todos.
